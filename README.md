# COOMTOCE IA Quest

Game educativo responsivo sobre decisões de uso de IA na medicina, com percursos para médicos(as) e gestores(as) de cooperativas.

## Jogar

A aplicação estática é publicada a partir da raiz deste repositório. Abra index.html ou sirva a pasta por HTTP. Não há build, backend, cadastro ou envio de respostas.

## Experiência

Quatro capítulos por percurso, ordem das respostas sorteada a cada capítulo, Sala de Evidências acessível dentro do jogo e auditoria final exportável em PDF ou texto. Consultar pistas influencia a leitura de certas decisões. As imagens e os casos são fictícios.

## Verificação

A fonte de trabalho e os testes de navegador ficam na pasta local V3 do projeto IA Quest. Foram verificados oito capítulos em nove tamanhos de tela, incluindo celular em paisagem, além da exportação em PDF A4 e texto para os dois percursos.

## Referência

O conteúdo se inspira na Resolução CFM nº 2.454/2026: https://sistemas.cfm.org.br/normas/arquivos/resolucoes/BR/2026/2454_2026.pdf. O resultado do jogo não é avaliação clínica, certificação ou parecer jurídico.
